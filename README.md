## Grid and Flexbox Usage
CSS Grid and Flexbox have been extensively used to design and structure the layout of this project:
- **CSS Grid:** 
  - `.kpi-grid` is used to layout the four KPI cards in a responsive grid structure[span_0](start_span)[span_0](end_span).
  - `.charts-grid` is used to neatly organize and distribute the two charts side by side[span_1](start_span)[span_1](end_span).
- **Flexbox:**
  - Used within `.topbar` and `.welcome-row` for item alignment and space distribution[span_2](start_span)[span_2](end_span).
  - Used in the sidebar and navigation menus to align links and elements properly[span_3](start_span)[span_3](end_span).
